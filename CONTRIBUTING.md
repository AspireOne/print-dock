# Contributing

Thanks for your interest in Print Dock!

## Ways to contribute
- Report bugs or request features via GitHub issues
- Improve documentation
- Submit pull requests

## Development

Run the checks for the implementation you change: see [Validation](README.md#validation) for the Python CLI and Windows integration, and for the native macOS targets.

## Pull requests
- Keep changes focused and well‑scoped
- Include tests for behavioral changes when possible
- Update docs if the public surface changes
